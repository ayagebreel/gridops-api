

# GridOps API

## Problem

Utility maintenance teams need a reliable way to track
network faults and manage maintenance work orders.

Without a centralized system, fault reports, work
assignments, required components, and maintenance
statuses can become difficult to track and coordinate.

GridOps provides a REST API that allows technicians
to report faults, supervisors to create work orders,
manage required components, and track work order
progress through controlled status transitions.

## Main Features

- Fault reporting
- Work order management
- Component management
- Work order component tracking
- Controlled work order status transitions
- Automated tests

## Technology Stack

- Python
- FastAPI
- SQLAlchemy
- Pydantic
- SQLite
- Pytest
- HTTPX
